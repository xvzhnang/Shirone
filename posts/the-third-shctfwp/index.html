脚本中验证 ddd 的逻辑基于以下代数关系：

  1. 已知：ϕ=(p−1)(q−1)=pq−(p+q)+1\phi = (p-1)(q-1) = pq - (p+q) + 1ϕ=(p−1)(q−1)=pq−(p+q)+1
  2. 代换：由于 n=pqn = pqn=pq，可以得出 p+q=n−ϕ+1p+q = n - \phi + 1p+q=n−ϕ+1。
  3. 构造方程：根据韦达定理， ppp 和 qqq 是方程 x2−(p+q)x+n=0x^2 - (p+q)x + n = 0x2−(p+q)x+n=0 的两个根。
  4. 判别式验证：我们只需要计算 D=(p+q)2−4nD = (p+q)^2 - 4nD=(p+q)2−4n。如果 DDD 是一个完全平方数，说明我们找到了正确的 ϕ\phiϕ（也就找到了正确的 ddd）。

[阶段1] Stream#

LCCCGGGGG

  1. 已知 P_known ⊕ C_known ⇒ 连续 LCG 输出

    用经典 LCG 参数恢复：

    • 差分法 + gcd 恢复 m
    • 解线性同余恢复 a, c

    复现 keystream，异或解出 FLAG

  2. 用已知明文 P_known 与对应的密文 C_known 按 8 字节块异或，得到若干连续的 LCG 输出（即 keystream 的块值）。

  3. 利用连续输出构造数列差分，计算若干值 t = d1^2 - d2*d0，对这些 t 取 gcd 可恢复出模数 m（这里 gcd 恰好等于 m）。

  4. 用模 m 与已知输出解出乘子 a、加数 c、以及初始种子 s0，并验证能重现已知 keystream。

  5. 用恢复出的 keystream 对 C_flag 对应的字节段逐字节异或，得到 FLAG 明文。
